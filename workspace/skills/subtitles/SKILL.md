# Субтитры

## Что сейчас на экране
`player` action `subtext` — текущая строка субтитров: снизу и, если стоят два языка, верхняя.
Это замена чтению `get_property sub-text` через socat: один вызов, без перемоток вслепую.

## Найти сцену по реплике («где поют гиены», «песня из Анастасии»)

СНАЧАЛА — чего делать НЕЛЬЗЯ. НЕ качай видеофайл с TorrServer (`/stream`, `curl -r`, в
`/data/local/tmp/*.mkv`) и НЕ запускай по его стриму ffmpeg/ffprobe, чтобы достать субтитры.
Проверено: файл — гигабайты, по торрент-стриму ffmpeg его не открывает (seekable-режим не
открывает, linear за полторы минуты доходит только до 10-й минуты). Это тупик, не трать время.

Правильный путь — внешний .srt:

1. `find_subtitles` (query — оригинальное название без сезона/серии, language, season/episode для
   серии) — список релизов субтитров в OpenSubtitles и SubDL (только поиск, не скачивание).
2. Скачай подходящий .srt (ссылку бери со страницы релиза; на крайний случай — subtitlecat).
   Это маленький текстовый файл, качается мгновенно — не путать с видеофайлом.
3. Найди в .srt нужную реплику с её таймкодом и перемотай туда: `player` seek `Ч:ММ:СС`.
4. Проверь попадание `player` subtext. Тайминг внешних субтитров часто смещён относительно
   конкретного релиза — подвинь seek'ом на несколько секунд.

Внешнего .srt не нашёл — НЕ уходи в скачивание видео. Честно скажи, что точно найти сцену не
получается, и предложи перемотать примерно (по памяти о фильме: песня из начала — минуты 2–4 и т.п.),
дальше уточняя через `player subtext`.

## Подключить скачанный .srt вторым языком
sub-add + secondary-sid (см. AGENT.md): текстовый файл встаёт сверху, дорожка из релиза — снизу.
