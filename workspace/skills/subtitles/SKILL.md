# Субтитры

## Что сейчас на экране
`player` action `subtext` — текущая строка субтитров: снизу и, если стоят два языка, верхняя.
Это замена чтению `get_property sub-text` через socat: один вызов, без перемоток вслепую.

## Найти сцену по реплике («где поют гиены», «песня из Анастасии»)

НЕ качай видеофайл с TorrServer целиком (`/stream`, `curl -r`, в `/data/local/tmp/*.mkv`):
он весит гигабайты.

Путь через внешний .srt:

1. `find_subtitles` (query — оригинальное название без сезона/серии, language, season/episode для
   серии) — список релизов субтитров в OpenSubtitles и SubDL (только поиск, не скачивание).
2. Скачай подходящий .srt (ссылку бери со страницы релиза; на крайний случай — subtitlecat).
   Это маленький текстовый файл, качается мгновенно — не путать с видеофайлом.
3. Найди в .srt нужную реплику с её таймкодом и перемотай туда: `player` seek `Ч:ММ:СС`.
4. Проверь попадание `player` subtext. Тайминг внешних субтитров часто смещён относительно
   конкретного релиза — подвинь seek'ом на несколько секунд.

Внешнего .srt не нашёл — распознай речь куска, где должна быть сцена, инструментом `transcribe`
(по памяти о фильме: песня из начала — минуты 2–4 и т.п.) и ищи реплику в распознанном.

## Подключить скачанный .srt вторым языком
`player` action `sub_add`, value — путь к файлу, place «top»: текстовый файл встаёт сверху, дорожка из
релиза — снизу.

## Субтитры разъехались со звуком
Один сдвиг не помогает (сдвиг плывёт или идёт ступеньками) — `transcribe` кусками через каждые ~5 минут
по всей серии («2:00,7:00,12:00,…») → `sync_subtitles` файла к распознанному (второй язык — так же или к
уже подогнанному первому) → `player sub_add` подогнанного файла. Ступенька лежит между кусками с разным
сдвигом, где образца нет, и стоит там по паузе в субтитрах: распознай кусок посередине и подгони заново,
пока такой промежуток не сузится до пары минут. Кусок «неоднозначно» — распознай другой рядом.
